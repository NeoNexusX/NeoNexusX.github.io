Token自由计划

本文介绍如何通过自建 API 中转站，统一管理和使用高质量模型 API。主要覆盖三类使用场景：

  • 使用 Cherry Studio 进行多模型对话。
  • 使用 CC Switch 管理 API 配置与模型代理。
  • 在 Codex 或 Claude Code 中接入自建 API 进行编程辅助。

模型与价格：https://api.neonexus.top/pricing

注意：文档中的 NEWAPI_CC_KEY、NEWAPI_CODEX_KEY、NEWAPI_CHERRY_KEY 均为占位符，请统一替换为你在第零节注册账号后自行创建的 API Key。

零、注册账号并获取 API Key

访问以下地址注册账号：

https://api.neonexus.top/

创建 API Key：

创建令牌时，建议根据实际使用场景选择对应的分组：

  • Claude Code：选择 Claude Code 专用分组。
  • Cherry Studio：支持多种接口，可选择 Auto 分组，由系统自动匹配。
  • Codex：仅支持 Responses 接口，因此使用 Codex 时请选择 Codex 专用分组。

分组在创建令牌时选定，之后每个 Key 只走自己的分组，因此建议一个分组建一个 Key：Claude Code、Codex、Cherry Studio 各创建一个令牌，分别对应上面三个分组。这样切换软件时就不用回后台反复改分组，也就是开头提到的 NEWAPI_CC_KEY、NEWAPI_CODEX_KEY、NEWAPI_CHERRY_KEY 三个占位符。

默认令牌分组选 Auto 即可，但模型显示可能不准确：有些模型仅支持 Claude 接口，有些仅支持 OpenAI 接口。如果只是先试试，可以先用 Auto；如果选了某个模型后一直没有回复或者报错，请把使用记录发给管理员：
